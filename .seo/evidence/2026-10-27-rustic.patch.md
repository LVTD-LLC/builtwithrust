## Before

## After

rustic is a Rust backup tool that stores encrypted, deduplicated snapshots. It reads and writes the restic repository format, but sharing a format does not make concurrent mixed-client operations safe. Do not run restic prune while rustic may be writing to the same repository: rustic does not honor restic's locks, and that overlap can leave the repository inconsistent.

It is designed for repeatable backup and restore workflows, with support for local and remote storage. Its command-line application builds on separate Rust libraries for backup operations and storage backends.
