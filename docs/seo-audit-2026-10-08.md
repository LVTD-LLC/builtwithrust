# SEO audit — October 8, 2026

## Scope and findings

Reviewed Axum/Maud templates, directory filters, cache paths, sitemap, robots, IndexNow, public links and 61 live sitemap URLs. Browser evaluation confirmed category heading and metadata findings.

- All 14 category routes had no H1. Search-result views also lacked a primary heading.
- Homepage plus 14 categories shared a generic description. Category titles and self-canonicals already distinguish routes.
- Homepage category select options are useful controls, but not crawlable links to category routes. Existing `/categories` remains a useful hub.
- No broken internal links found in the crawl. Filter variants retain base canonicals. IndexNow is already configured; acceptance is not indexing evidence.
- One rendered category had no JSON-LD. Structured data remains a separate improvement, not an indexing blocker.
- Initial latency measurements were contaminated by intermittent resolver/network delays. Do not interpret them as field Core Web Vitals or proof that the application is slow.

## Selected improvement

Repair category discovery: one H1 on category/search pages, category-specific descriptions and direct homepage category anchors. Keep existing URLs, filters, featured order, query handling and cached default pages. No database changes or new public pages.

Candidate ranking (judgment scores, not forecasts): category discovery repair 25 (movement 3 × confidence 4 + strategic 4 + freshness 5 + effort 4); category editorial enrichment 19 (2 × 3 + 4 + 5 + 4), held for use-case evidence; structured-data enhancement 16 (2 × 2 + 3 + 5 + 4), deferred behind visible discovery. No traffic-growth claim is made.
