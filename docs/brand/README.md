# Built with Rust brand kit

The folder tab in the crab’s shell represents the project directory. Use the symbol for avatars and the full wordmark when introducing the directory.

| Use | Artwork |
| --- | --- |
| Social profile | [1024 × 1024 PNG](../../assets/brand/profile-1024.png) · [400 × 400 PNG for X](../../assets/brand/x-profile.png) · [scalable square](../../assets/brand/profile.svg) |
| X cover | [1500 × 500 PNG](../../assets/brand/x-header.png) · [vector source](source/x-header.svg) |
| Shared link or pinned post | [1200 × 630 PNG](../../assets/brand/directory-card.png) · [vector source](source/directory-card.svg) |
| Transparent logo | [Ink symbol](../../assets/brand/mark-ink.svg) · [Cream symbol](../../assets/brand/mark-cream.svg) · [Ink wordmark](../../assets/brand/wordmark-ink.svg) · [Cream wordmark](../../assets/brand/wordmark-cream.svg) |
| Browser and home-screen icons | [SVG](../../assets/favicon.svg) · [32 px PNG](../../assets/favicon-32.png) · [ICO](../../assets/favicon.ico) · [180 px Apple touch icon](../../assets/apple-touch-icon.png) |
| Project spotlight | [Tokei example](project-spotlight-tokei.png) · [editable template](source/project-spotlight-template.svg) |

Upload the square profile image at its default crop. Both claws fit inside the circle. The X cover keeps its headline clear of the profile overlay.

Use ink (`#211E1C`) on orange (`#FF794D`) or cream (`#FFF2DB`). Peach (`#FFB394`) is the secondary folder color. Use the cream wordmark on dark surfaces.

The spotlight template uses Barlow Semi Condensed Bold for headlines, Barlow Medium for body copy and IBM Plex Mono Medium for labels. Replace the project name, description, category and URL, then export at 1200 × 630. The finished wordmarks, cover and link card have outlined type.
